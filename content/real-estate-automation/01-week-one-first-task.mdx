```python
import pandas as pd

# Fixed date for the sample file. On your own data, use pd.Timestamp.today().
TODAY = pd.Timestamp("2026-10-12")

# 1. Read the file. parse_dates turns the text into real dates.
leads = pd.read_csv("leads.csv", parse_dates=["last_contact"])

# 2. How long since you last spoke to each lead?
leads["days_since_contact"] = (TODAY - leads["last_contact"]).dt.days

# 3. Keep only the leads quiet for 7 days or more, longest first.
follow_up = leads[leads["days_since_contact"] >= 7]
follow_up = follow_up.sort_values("days_since_contact", ascending=False)

# 4. Show the list.
print(follow_up[["lead_id", "name", "days_since_contact"]])
```
